# Constituição para Agentes de IA & Skills

Palestra (15–20 min) sobre **constituição para agentes de IA** — o primeiro
artefato durável que um dev escreve ao migrar de *consumidor* para *configurador*
de IA — e a ponte natural para as *skills*.

## Ideia central

Convenção diz *como* fazemos as coisas. Constituição diz *o que nunca pode
acontecer* e *o que fazer na dúvida* — governa o **julgamento** do agente, não o
estilo. É um conceito **agnóstico de ferramenta** (`AGENTS.md` como padrão
aberto; Claude Code via `/init` + `@AGENTS.md`).

## Pendências do apresentador

- **Slide 7 + demo:** os placeholders `‹...›` são onde entram as linhas **reais**
  da constituição do apresentador (a colar depois).
- **Demo ao vivo (slide 10):** repo real + tarefa a definir; formato antes/depois
  (Run 1 pré-encenado, Run 2 ao vivo).

> Uma constituição é a primeira coisa que você escreve quando para de repetir
> instruções pra IA e começa a governá-la — e é o mesmo instinto que vira sua
> primeira skill.
